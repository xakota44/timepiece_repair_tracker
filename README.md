# timepiece_repair_tracker
A tool for me to track my watch and clock repairs I do for others or on my own pieces.

I do a lot of work on clocks and watches as my side-gig, but I am terrible at noting down things I've learned about specific types of movements or quirks to each brand/model. I plan to build a tool here soon that will allow for entries of work records that will include the manufacturer, year, model, movement type, notes, etc. Hopefully this will become my personal and maybe public knowledge base for horology and maybe I can avoid making the same mistakes in the future!
